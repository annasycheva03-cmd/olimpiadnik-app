# Олимпиадник: сборка APK для Android

Нужно один раз установить на компьютер:
1. Node.js LTS (nodejs.org)
2. Android Studio (developer.android.com/studio). При первом запуске согласитесь скачать Android SDK, JDK уже входит в Android Studio.

## Сборка

Откройте терминал в папке проекта (где лежит этот файл) и выполните по очереди:

```
npm install
npx cap add android
npx cap sync android
npx cap open android
```

В Android Studio дождитесь окончания синхронизации Gradle (полоса внизу, 3–10 минут при первом запуске), затем:

**Build → Build Bundle(s) / APK(s) → Build APK(s)**

Когда сборка закончится, внизу справа появится «Locate». Файл лежит в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Установка на телефон

1. Отправьте `app-debug.apk` на телефон (Telegram, почта, USB).
2. Откройте файл и разрешите установку из этого источника.
3. При первом запуске разрешите уведомления.

Напоминания планируются на телефоне: в 09:00 за день и в день олимпиады, даже если приложение закрыто.

## Если нужно выложить в магазин

Debug-версию нельзя публиковать. Для RuStore и Google Play нужна подписанная версия: Build → Generate Signed Bundle / APK, ключ создаётся там же. Сохраните файл ключа и пароли: без них приложение нельзя будет обновить.

## Обновление данных

Список олимпиад находится в `www/index.html` (массив `O` и таблица `EX`). После правки выполните `npx cap sync android` и соберите APK заново.
